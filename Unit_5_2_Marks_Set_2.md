### Q1. What is the fundamental difference between Type 1 and Type 2 Hypervisors?
**Answer:**
* **Type 1 (Bare-Metal Hypervisor):** Runs directly on the physical host hardware without an underlying host OS (e.g., VMware ESXi, KVM, Xen). Offers near-native performance and enterprise isolation.
* **Type 2 (Hosted Hypervisor):** Runs as an application software layer on top of an existing host operating system (e.g., Oracle VirtualBox, VMware Workstation). Incurs higher I/O overhead.

### Q2. Define Paravirtualization and state how it differs from Full Virtualization.
**Answer:**
* **Paravirtualization:** The guest operating system is modified with specific hypercalls to communicate directly with the hypervisor (e.g., Xen PV).
* *Difference:* Unlike Full Virtualization (which simulates entire underlying hardware and requires binary translation for privileged ring 0 calls), Paravirtualization does not require binary translation, achieving superior performance at the cost of guest OS kernel modification.

### Q3. How do Linux Namespaces and Control Groups (cgroups) enable Containerization?
**Answer:**
* **Namespaces:** Provide resource **isolation** by creating private system views (PID, NET, MNT, IPC, UTS, USER) for each container.
* **Control Groups (cgroups):** Provide resource **metering and throttling**, enforcing hard boundaries on CPU, memory, network bandwidth, and disk I/O.

### Q4. Differentiate between Block Storage and Object Storage in cloud architectures.
**Answer:**
* **Block Storage:** Data is sliced into raw, fixed-size blocks addressed by Logical Block Addresses (LBA) with zero metadata. Ideal for databases and OS root drives requiring ultra-low latency (e.g., AWS EBS).
* **Object Storage:** Data is stored as discrete objects containing data, globally unique 128-bit IDs, and extensible metadata accessed via RESTful HTTP APIs. Horizontally scalable with flat namespace (e.g., AWS S3).

### Q5. What is the role of the Secondary NameNode in Hadoop HDFS?
**Answer:**
* The **Secondary NameNode** is **not** a hot-standby high-availability failover.
* Its dedicated function is to perform checkpointing: it periodically merges the NameNode's memory image (`fsimage`) with the edit transactions log (`edits`), preventing the edit log from growing unbounded.

### Q6. Explain the function of the Combiner in the MapReduce execution pipeline.
**Answer:**
* A **Combiner** is an optional "mini-reducer" that executes locally on the mapper node.
* It aggregates intermediate key-value pairs generated by the local `map()` function before network transmission, drastically cutting network shuffle bandwidth.

### Q7. Distinguish between Horizontal Auto-scaling and Vertical Auto-scaling.
**Answer:**
* **Horizontal Scaling (Scale-out / Scale-in):** Adds or removes virtual machine instances or container pods dynamically in response to traffic load.
* **Vertical Scaling (Scale-up / Scale-down):** Increases or decreases CPU, RAM, or storage capacities of an existing running virtual instance (often requires downtime or hot-plug support).

---

### Q8. What is a Virtual Machine Escape (VM Escape) attack?
**Answer:**
* **VM Escape:** A high-severity vulnerability where malicious code running inside an isolated guest virtual machine exploits a bug in the hypervisor to break out of the VM boundary and execute arbitrary commands directly on the host hypervisor or host OS.

---

### Q9. Differentiate between Layer 4 (L4) and Layer 7 (L7) Cloud Load Balancers.
**Answer:**
* **Layer 4 Load Balancer (Transport Layer):** Routes traffic based strictly on IP addresses and TCP/UDP port numbers without inspecting application payload. Delivers ultra-high throughput and microsecond latency.
* **Layer 7 Load Balancer (Application Layer):** Inspects HTTP/HTTPS headers, URLs, cookies, and payloads to make intelligent application routing decisions (e.g., path-based routing `/api` vs `/static`).

---

### Q10. Define Service Level Objective (SLO) versus Service Level Agreement (SLA).
**Answer:**
* **SLO (Service Level Objective):** A specific, measurable target metric for service reliability (e.g., $99.99\%$ API availability, response latency $< 200\text{ ms}$).
* **SLA (Service Level Agreement):** The legally binding contract between cloud provider and customer that incorporates SLOs and specifies financial penalties or service credits if SLOs are violated.

---

### Q11. How does Consistent Hashing minimize data movement in cloud distributed caches?
**Answer:**
* Consistent Hashing maps both cluster nodes and cache keys to positions on an identical $2^{128}$ or $2^{160}$ circular hash ring.
* When a node is added or removed, only $K/N$ keys need to be remapped to adjacent nodes (where $K$ is total keys and $N$ is total nodes), avoiding the total $\approx 100\%$ key invalidation of traditional modulo hashing (`key % N`).

### Q12. What is Multi-Tenancy in cloud computing, and what security challenge does it introduce?
**Answer:**
* **Multi-Tenancy:** The architectural sharing of identical physical hardware (compute cores, memory, storage backplanes) among multiple distinct, mutually untrusted customers (tenants).
* **Security Challenge:** Risk of cross-tenant side-channel attacks (e.g., cache-timing attacks, Meltdown/Spectre) and noisy-neighbor resource starvation.
